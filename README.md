# מסלול לימוד — Studious

אפליקציית Android אופליין מלאה למעקב לימוד אישי.

## עקרונות
- ללא שרת וללא צורך באינטרנט בזמן השימוש.
- נתוני המשתמש נשמרים במכשיר בלבד.
- ששת סדרי המשנה מובנים באפליקציה.
- יעד סיום, קצב יומי, רצף, סטטיסטיקות והתראות מקומיות.
- ממשק RTL בעברית.
- ניתן לערוך הקדשה ונוסח תזכורת.

## Build
פתחו את הפרויקט ב-Android Studio והריצו:
./gradlew assembleDebug

ה-APK יופיע תחת app/build/outputs/apk/debug/.
